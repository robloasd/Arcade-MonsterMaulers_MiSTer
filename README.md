## 🎮 What Is Monster Maulers?

Monster Maulers is a one-on-one fighting game released by Konami in 1993. Players choose from a roster of bizarre combatants and battle across themed stages, chaining punches, throws, and special moves against larger-than-life opponents. The original game ran on Konami's GX170 arcade hardware, a board that has historically been difficult to emulate perfectly.

This project recreates that hardware inside an FPGA chip. The result is a game that behaves like the original arcade machine — same speed, same collision, same sound — while being playable on a MiSTer setup connected to a modern display or CRT.

## ✨ What Makes This Core Special

- **Hardware-accurate gameplay** — the core recreates the GX170 arcade board logic rather than approximating it in software, so the game runs at the correct speed with the original timings.
- **Two classic titles in one lineage** — the core is built around the same hardware family that powers the Dadandarn / Monster Maulers releases, so the whole arcade experience is preserved.
- **Written in SystemVerilog and Verilog** — the core is open and readable, built for the Cyclone V chip found in MiSTer hardware.
- **Made for real displays** — works with HDMI monitors and televisions as well as traditional CRT screens.
- **Part of a large arcade library** — drops neatly into the standard MiSTer arcade folder structure alongside your other cores.
- **Active, community-driven project** — improvements and fixes are shared openly through the GitHub repository.

## 🕹️ Playing the Game

When Monster Maulers loads, you are greeted by the original arcade attract mode. Press your Start button to leave it and reach the character select screen. Pick a fighter, and you will be dropped into a match with the standard arcade controls:

- **Joystick or D-pad** — move your character toward and away from your opponent.
- **Punch button** — light and heavy attacks, depending on how the buttons are mapped in your MiSTer controller settings.
- **Kick button** — the second attack button from the original cabinet layout.
- **Start** — begin a match or continue after a loss.

Take a few minutes to test each button in the first match. If a button does nothing, open the MiSTer main menu, go to the controller settings, and map each physical button to the matching arcade input. Getting this right makes the game far more enjoyable, since Monster Maulers relies heavily on quick combinations.

## ⚙️ Configuration Tips

- **Save your settings.** The MiSTer menu lets you save a configuration per core so your button mapping and video options stick around next time.
- **Video scaling.** If the picture looks stretched or has borders, adjust the scaling options in the core menu. Turning on integer scaling gives the cleanest, sharpest image on modern televisions.
- **Audio.** If sound is coming out of the wrong output, use the MiSTer audio settings to switch between HDMI and analog output.
- **Overscan.** Some older televisions cut off the edges of the picture. If the health bars are clipped, reduce the overscan value in the core's video menu.
- **Performance.** FPGA hardware runs the game at full speed regardless of your PC, because the MiSTer itself does all the work. Your Windows machine is only used to prepare the SD card.

## 🔧 Troubleshooting Common Problems

**The game does not appear in the arcade menu.** The files are probably in the wrong folder. Compare the folder path with an existing working arcade core and match it exactly.

**The game appears but will not launch.** The required ROM files may be missing or named incorrectly. Check that the file names match what the core expects, character for character.

**The screen is black but the MiSTer menu works.** Try a different video output or resolution setting. Some displays need a few seconds to lock onto the signal.

**Controls feel unresponsive.** Re-map the buttons in the MiSTer controller menu, then save the configuration so it is remembered.

**Sound is missing or crackling.** Check the audio output setting and confirm your HDMI cable or analog cable is fully seated.

**Nothing works after copying files.** The SD card may have been removed without being safely ejected. Reconnect it, copy the files again, and eject properly this time.
